
## 环境介绍

测试服务器有**两块网口**（两个独立网卡/端口），职责不同，勿混用：

| 网口 | 设备名（实板） | IP / 用途 | 连接对象 |
|------|----------------|-----------|----------|
| **管理网口** | `enp25s0f0` | `192.168.49.81/24` | SSH 登录、热插拔脚本 |
| **GMAC 测试网口** | `enp25s0f1` | 调试时配 `192.168.1.1/24`（勿配 `49.81`） | 网线直连 EP RJ45 |

1、服务器 SSH：`lynxi@192.168.49.81`，密码为 `1`（走**管理网口**）。
2、调试设备作为 EP，串口经 `/dev/ttyUSB0` 接服务器；**网口只接**服务器 `enp25s0f1`（**测试网口**，与 `49.81` 不是同一块卡）。
3、EP 固件侧 IP 为 `192.168.1.2`（RT/Zephyr GMAC 配置），与 Host 测试口 `192.168.1.1` 同网段互 ping。

3、**编译在本地**，49.81 已挂载工程目录（`/mnt/49.20/...` 与本地工作区同一份代码），**无需 scp 上传固件**。本地 `scons` 生成 `rtthread.bin` 后，49.81 通过软链直接加载：

```
# 本地编译（示例）
cd bsp/lynxi/he200
export RTT_CC_PREFIX=.../aarch64-none-elf-
scons -j8    # 生成 rtthread.bin

# 49.81 上软链（已配置则无需改）
ls -l /lib/firmware/lynd_pcie/u-boot.bin
# -> /mnt/49.20/rt-thread/bsp/lynxi/he200/rtthread.bin
```

4、本地编译完成后，在 49.81 执行热插拔即可加载最新固件（读挂载目录里的 bin）：
```
periph_slv_test/hotplug_wdt.sh --devid 0
```
环境准备脚本：[`scripts/he200_test_env.sh`](scripts/he200_test_env.sh)（配置 `enp25s0f1` 为 `192.168.1.1/24`）。

**每次 GMAC 验收前必查**（NetworkManager 可能把 `49.81` 写回测试口）：

```bash
bash scripts/he200_test_env.sh
ip -4 addr show enp25s0f1   # 只能有 192.168.1.1/24，不能有 192.168.49.81
```

热插拔等待期间也可能被改回；**ping 前再跑一次脚本**。

调试方法汇总：[`DEBUG_SKILL.md`](DEBUG_SKILL.md)
